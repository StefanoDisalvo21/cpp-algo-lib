## This is a simple C++ algorithm library meant to learn Algorithms and Data Structure

## About this project

    The project started in May 2026 during the last month of high school. 
    An Algorithms library is the first thing I thought to, after having worked
    on small projects, now my knowledge in my opinion needs to be improved and
    that's a good way to still write code while learning new fundamental concepts.
    The idea comes from the will of making more than the regular HS student
    and be more prepared for the faculty of Computer Engineering, which I will
    start in September 2026.

    The repo will be updated whenever a new algorithm is learnt, it won't be 
    regular since the learning path is not linear too, the goal is to be ready
    two years from now for the Data Structure & Algorithm.
    

## Goals 🎯
    - Learn About Algorithms
    - Learn About Data Structures
    - Improve git  skills 
    - Learn how to write tests using "Google Test".
